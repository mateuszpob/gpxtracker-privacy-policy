Privacy Policy – GPXTracker

Your privacy is important to us. The GPXTracker application works mainly locally on the user's device. Track files and location data are not transmitted to the app developers.

Firebase Analytics

The application uses the Google Firebase Analytics service to collect anonymous statistics about application usage and to improve its operation.

Information about interactions with the application may be collected, such as feature usage, screen openings, or interface button clicks. This data is not used to identify the user.

The following data is not sent to Firebase Analytics:

  • user GPX tracks,
  • GPS coordinates,
  • user file names,
  • email addresses or contact information,
  • other data that could directly identify the user.

GPX Files

The application saves and reads GPX files only locally on the user's device. You can open existing GPX files from device storage or other available locations.

Data contained in GPX files is not transmitted to the app developers or any external services.

Location Data

The application uses location permissions: ACCESS_COARSE_LOCATION, ACCESS_FINE_LOCATION, and ACCESS_BACKGROUND_LOCATION only to display the user's position on the map and save tracks in GPX format.

Location data remains on the user's device and is not transmitted to any third parties.

Elevation Data (Optional)

By default, the app uses local GPS data for elevation. If you explicitly enable the OpenTopoData service in settings, the app transmits a simplified, sampled subset of your coordinates (limited to 100 points per track) to opentopodata.org to retrieve high-precision topographic data (SRTM 30m). This minimizes data transmission while significantly improving the accuracy of your elevation profiles.

Permissions

  • Location: displaying the user's position on the map and recording tracks.
  • Storage / files: saving and reading GPX files.

Data Storage

All data related to user tracks is stored locally on the user's device. The application does not have its own server that stores user data.

External Services

The application uses the following service:

  • Google Firebase Analytics – anonymous analysis of application usage.

Information about Google's privacy practices is available in Google's documentation.

User Age

The application is intended for users of all ages.

Polityka prywatności – GPXTracker

Twoja prywatność jest dla nas ważna. Aplikacja GPXTracker działa głównie lokalnie na urządzeniu użytkownika. Pliki tras oraz dane lokalizacyjne nie są przesyłane do twórców aplikacji.

Firebase Analytics

Aplikacja korzysta z usługi Google Firebase Analytics w celu zbierania anonimowych statystyk dotyczących korzystania z aplikacji oraz poprawy jej działania.

Zbierane mogą być informacje dotyczące interakcji z aplikacją, takie jak użycie funkcji, otwieranie ekranów lub kliknięcia elementów interfejsu. Dane te nie służą do identyfikacji użytkownika.

Do Firebase Analytics nie są przesyłane dane takie jak:

  • trasy GPX użytkownika,
  • współrzędne GPS,
  • nazwy plików użytkownika,
  • adres e-mail ani dane kontaktowe,
  • inne dane pozwalające bezpośrednio zidentyfikować użytkownika.

Pliki GPX

Aplikacja zapisuje i odczytuje pliki GPX wyłącznie lokalnie na urządzeniu użytkownika. Możesz otwierać istniejące pliki GPX z pamięci urządzenia lub innych dostępnych lokalizacji.

Dane zawarte w plikach GPX nie są przesyłane do twórców aplikacji ani do usług zewnętrznych.

Dane lokalizacji

Aplikacja korzysta z uprawnień lokalizacji: ACCESS_COARSE_LOCATION, ACCESS_FINE_LOCATION oraz ACCESS_BACKGROUND_LOCATION wyłącznie w celu wyświetlania pozycji użytkownika na mapie oraz zapisywania tras w formacie GPX.

Dane lokalizacyjne pozostają na urządzeniu użytkownika i nie są przesyłane do żadnych podmiotów zewnętrznych.

Dane wysokościowe (opcjonalne)

Domyślnie aplikacja wykorzystuje lokalne dane GPS do określania wysokości. Jeśli użytkownik wyraźnie włączy usługę OpenTopoData w ustawieniach, aplikacja przesyła uproszczony, próbkowany fragment współrzędnych trasy (ograniczony do maksymalnie 100 punktów na trasę) do opentopodata.org w celu pobrania bardzo dokładnych danych topograficznych (na podstawie zbioru danych SRTM 30 m).

Takie rozwiązanie ogranicza ilość przesyłanych danych, jednocześnie znacząco poprawiając dokładność profili wysokościowych tras.

Uprawnienia

  • Lokalizacja: wyświetlanie pozycji na mapie oraz zapis tras.
  • Pamięć / pliki: zapis i odczyt plików GPX.

Przechowywanie danych

Wszystkie dane związane z trasami użytkownika są przechowywane lokalnie na urządzeniu użytkownika. Aplikacja nie posiada własnego serwera przechowującego dane użytkowników.

Usługi zewnętrzne

Aplikacja korzysta z usługi:

  • Google Firebase Analytics – anonimowa analiza użycia aplikacji.

Informacje dotyczące zasad prywatności Google dostępne są w dokumentacji Google.

Wiek użytkowników

Aplikacja jest przeznaczona dla użytkowników w każdym wieku.
